# Backend NestJS (arquivado)

Código movido da raiz do repositório na fase 5. **Não é usado em produção** — o app usa Supabase diretamente.

## Conteúdo

- `src/` — módulos Nest (finance, companies, entities_mgmt)
- `test/` — testes Jest do Nest

## Restaurar localmente (opcional)

1. Mover esta pasta de volta ou clonar do histórico git
2. Reinstalar dependências Nest no `package.json` (ver commit anterior)
3. `npm run nest:start:dev`
